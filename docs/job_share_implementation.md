# مشاركة تفاصيل الوظيفة

تعتمد شاشة تفاصيل الوظيفة على `share_plus: ^12.0.2`، وهو إصدار متوافق مع اعتماد `file_picker` القائم في المشروع. على Flutter Web ينسخ `JobShareService` الرابط الفعلي من `Uri.base` إلى الحافظة، حتى يكون الرابط الذي يشاركه المستخدم هو رابط الوظيفة المفتوحة نفسها. أما على المنصات غير الويب فتستخدم الخدمة واجهة المشاركة الأصلية عبر `SharePlus.instance.share(ShareParams(...))` مع نص عربي لا يتضمن أي بيانات تعريفية للمستخدم.

استندت واجهة الاستدعاء إلى توثيق الحزمة المنشور في 2026-08-21: [share_plus على pub.dev](https://pub.dev/packages/share_plus). يوضح التوثيق استخدام `SharePlus.instance.share` و`ShareParams` لمشاركة النص، ودعم الحزمة للويب وأندرويد وiOS.
