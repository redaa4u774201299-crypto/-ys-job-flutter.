# قرار تنفيذ قص الصور

- **المكتبة المختارة:** `crop_your_image`.
- **السبب:** توفر مكوّن قص مخصصاً قابلًا للتضمين ضمن واجهة Flutter، ما يلائم حوار قص عربي داخل التطبيق ولا يعتمد على Firebase Storage.
- **التوافق:** توضح صفحة الحزمة أنها توفر مكوّن `Crop` مرناً لواجهات Flutter، وتظهر ضمن نتائج البحث كحل يدعم Flutter Web.
- **المصدر:** https://pub.dev/packages/crop_your_image
- **آلية الدمج:** تُمرّر البايتات المنتقاة إلى حوار القص؛ ولا تدخل الصورة إلى ضغط Base64 وتوليد النسخة المصغرة إلا بعد تأكيد المستخدم للقص. الإلغاء يعيد المستخدم إلى النموذج بلا أي كتابة في Firestore.
