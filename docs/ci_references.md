  - يوضح أن سير العمل يمكن تشغيله عند أحداث المستودع، ومنها الدفع وطلبات الدمج.

  - مرجع لمكونات سير العمل ومشغلاته.

  - مرجع رفع ناتج بناء الويب كأثر قابل للتحميل بعد نجاح التحقق.
- Flutter Docs — **Build and release a web app**: https://docs.flutter.dev/deployment/web
  - مرجع بناء واختبار تطبيقات Flutter Web.
- GitHub — **actions/upload-artifact**: https://github.com/actions/upload-artifact
  - المرجع الرسمي لاستخدام إجراء رفع ملفات البناء في GitHub Actions.
